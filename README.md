# Textbox Fixes

[![Join Discord](https://img.shields.io/badge/Join-Discord-5865F2?style=for-the-badge&logo=discord&logoColor=white)](https://discord.gg/bX4RzunsxC)

Fixes text boxes where long names become difficult to read, lines disappear, or the cursor goes outside the field.

Display Name and other text properties get a larger box below their label, with word wrapping and vertical scrolling. The box follows your cursor as you type or move through the text. Typing in these boxes also blocks WASD and other editor shortcuts, so you can write without moving the camera or rotating parts.

Vehicle save names stay on one line. The text scrolls horizontally as you move the cursor, keeping both the text and cursor inside the field.

Text size and the height of the larger boxes can be changed in the mod's settings. Text defaults to 80% size. Restart the game after changing these settings.

## Installing

To use, install [SWML](https://github.com/kiVts/swml), then add `textbox_fixes.zip` from this repository's releases through the loader's **Add mod...** button. Enable **Text Fields** and restart Stormworks.

If a game crashes feel free to make an issue here and [join the discord](https://discord.gg/SsT4Y6Y3Zm) so the process to fixing them is quicker.

I also recommend installing [No Crash Uploads](https://github.com/kiVts/no_crashlog_upload) so you don't upload a crash report with an injected DLL to Geometa and (And a crash reason overwhelmingly likely to be due to one of these mods). Consider these other mods as well!
